# SwiftUI 100本ノック

## SwiftUIを習得するための学習です。

### カテゴリ1: SwiftUIの基本 (1-10)
SwiftUIの基本的なビュー、レイアウト、状態管理を理解する。

1.テキスト表示: シンプルな「Hello, World!」を表示するTextビューを作成。
2.画像表示: Imageビューを使ってローカルの画像を表示（アセット追加）。
3.ボタン作成: ボタンを押すとテキストが変化するシンプルなButtonを作成。
4.VStackでレイアウト: 複数のTextを縦に並べるVStackを使用。
5.HStackでレイアウト: 複数のTextやImageを横に並べるHStackを使用。
6.Spacerの活用: Spacerを使ってビューを画面の端に寄せるレイアウトを作成。
7.状態管理 (@State): @Stateを使ってテキストフィールドの入力値をリアルタイムで表示。
8.リスト表示: Listビューを使って静的なアイテムリストを表示。
9.カスタムモディファイア: Textにフォントサイズや色を適用し、モディファイアをカスタマイズ。
10.基本アニメーション: ボタンタップでビューの表示/非表示をアニメーションで切り替え。
